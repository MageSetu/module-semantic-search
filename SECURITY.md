# Security Policy

## Supported Versions

Only the latest release receives security attention.

| Version | Supported |
| ------- | --------- |
| 1.0.0   | ✅ Yes    |

Older releases, if any, are not patched.

## Reporting a Vulnerability

**Do not open a public GitHub issue or pull request to report a security problem.**

Use GitHub's Private Vulnerability Reporting instead:

1. Go to the repository on GitHub.
2. Click the **Security** tab.
3. Open **Advisories**.
4. Click **Report a vulnerability**.

Your report will be visible only to the repository maintainers until it is resolved.

When submitting a report, please include:

- The module version (`magesetu/module-semantic-search`)
- Magento version
- PHP version
- Clear steps to reproduce the issue

## No Guarantees

This is an individually maintained open-source project. Reports are reviewed on a best-effort basis. There is no guaranteed response time, fix time, or service-level agreement, and no bug bounty is offered.
